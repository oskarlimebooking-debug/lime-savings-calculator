# Step components (category / region / no-shows)

Build controlled components `CategoryPicker`, `RegionPicker`, `NoShowInput` (slider + numeric, weekly/monthly toggle). Each is a pure controlled component taking `value`+`onChange`. Keep selection/formatting logic in exported helpers so it is headlessly testable without a DOM render.

# Acceptance Criteria

- [x] AC1: `NoShowInput` helper clamps out-of-range slider/numeric values to [min,max] (vitest on the helper)
- [x] AC2: Weekly/monthly toggle helper converts the displayed count correctly between modes (asserted)
- [x] AC3: `CategoryPicker`/`RegionPicker` option lists are derived from `lib/data.ts` (length matches data, asserted via imported helper)
- [x] AC4: Components typecheck with strict prop types (`tsc --noEmit` passes)
