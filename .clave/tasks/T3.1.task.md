# Fokus ring, kontrast in dotikalne tarče

Vsak interaktiven element dobi vse tri stanja (hover / focus / active). Fokus je vedno sage `#74B587` ring v obeh temah. Minimalna dotikalna tarča 44px na mobilnem. Dodaj čisto pomožno funkcijo `contrastRatio(fg, bg)` v `src/lib/ui.ts` in z njo v testih preveri uporabljene pare besedilo/ozadje.

# Acceptance Criteria

- [x] AC1: Vitest: `contrastRatio('#FFFFFF', '#447856') >= 4.5` in `contrastRatio('#181818', '#FAFAFA') >= 4.5`
- [x] AC2: Vitest: vsi pari telesnega besedila iz tokenov (svetla in temna tema) dosežejo ≥ 4.5 (zankan test nad preslikavo parov)
- [x] AC3: Vitest: `buttonClass` za vse variante in velikosti vrne razred z minimalno višino ≥ 44px (`min-h-11` ali ekvivalent)
- [x] AC4: Vitest prebere vse datoteke v `src/components` in trdi, da nobena ne uporablja `outline-none` brez spremljajočega `focus-visible:ring`
