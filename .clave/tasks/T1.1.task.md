# Zamenjava barvnih tokenov z Lime Booking paleto

Trenutni `tailwind.config.ts` uporablja generično Tailwind `lime` lestvico (`#22c55e`/`#16a34a`), ki ni Lime Booking blagovna znamka. Dodaj pravo paleto: brand sage `#74B587` (identiteta, focus ring, poudarki), CTA `#548F68` (hover `#447856`, pressed `#3D6D4D`), success `#4FB870`, warning `#EDA300`, danger `#F46969`, default `#8C8C8C`, ter accent paleto (vanilija `#FDF6DD`, mango `#EDA300`, breskev `#F6DFDF`, bežev `#F7F3FA`, sivka `#A881C6`, hortenzija `#E0ECF4`, plavica `#2D8CCA`) kot ločen `accent` ključ. V `globals.css` posodobi CSS spremenljivke (`--accent`, `--accent-light` → sage wash `rgba(116,181,135,.14)`, `--bg #FAFAFA`, `--card #FFFFFF`, `--warning #EDA300`). Stare `lime.*` ključe ohrani le kot alias, če jih kaj še uporablja — brez vzporednih sistemov.
