# Scaffold Next.js 14 + TS + Tailwind with Lime tokens

Initialize a Next.js 14 App Router project in TypeScript with Tailwind, mirroring the Lime stack in `../lime-api-v2`. Add the `lime` color scale (50–900), CSS vars (`--accent #16a34a`, `--accent-light #dcfce7`, `--bg #f8faf9`, `--card #fff`, `--warning #f59e0b`) and the `popIn`/`slideUp`/`fadeIn` keyframes to `globals.css`. Add vitest + `test`/`typecheck` npm scripts.
