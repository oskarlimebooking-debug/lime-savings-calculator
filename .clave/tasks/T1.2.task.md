# Inter tipografska lestvica namesto Geist/Arial

`layout.tsx` nalaga Geist, `globals.css` pa telo postavi na `Arial, Helvetica, sans-serif`. Preklopi na Inter (`next/font/google` ali lokalni woff2) in dodaj Lime univerzalno lestvico kot Tailwind `fontSize` tokene — ista na vseh prelomnih točkah: H1 24/32·600·−0.25px, H2 20/28·600·−0.25px, H3 18/26·600, H4 16/22·600, body-l 16/24·400, body-m 14/21·400, subtitle 13/18·500, caption 12/17·400, button 14/17·500, label 11/15·500 uppercase 0.4px. Odstrani neuporabljene Geist woff datoteke.
