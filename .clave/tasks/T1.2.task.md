# Price/region/category data module

Create a typed `lib/data.ts` (or JSON + loader) holding categories (frizerstvo, brivstvo, kozmetični saloni, druge lepotne storitve), SI regions (osrednjeslovenska, celjska, maribor, primorska, gorenjska, ostalo) plus optional HR/RS, and an approximate average price per category×region. Include a documented `NOSHOW_REDUCTION = 0.6` and `LIME_MONTHLY_PRICE` constant, each with a source comment.

# Acceptance Criteria

- [ ] AC1: `getPrice(category, region)` returns a positive finite number for every valid category×region combination (vitest loops all combos)
- [ ] AC2: `getPrice` throws or returns a documented fallback for unknown keys (asserted)
- [ ] AC3: `CATEGORIES` and `REGIONS` arrays each have unique slug keys (vitest Set-size assertion)
- [ ] AC4: `NOSHOW_REDUCTION` is within [0.5, 0.7] and `LIME_MONTHLY_PRICE > 0` (asserted)
- [ ] AC5: Every category exposes a price entry for every region (no undefined gaps, asserted)
