# URL param serialization/parsing

Implement `lib/urlState.ts`: `parseParams(searchParams)` → validated `{category, region, noshows, period}` with safe defaults and clamping (noshows ≥ 0, valid enums only); `toQueryString(state)` producing `?category=…&region=…&noshows=…&period=…`. Round-trip stable.

# Acceptance Criteria

- [x] AC1: `parseParams(toQueryString(state))` deep-equals the original valid state (round-trip vitest)
- [x] AC2: Invalid/missing params resolve to documented defaults, never throw (asserted with garbage input)
- [x] AC3: `noshows` is coerced to a non-negative integer; negatives/NaN clamp to 0 (asserted)
- [x] AC4: Unknown category/region enum values fall back to the first valid option (asserted)
